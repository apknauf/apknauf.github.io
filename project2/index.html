Topic Description

The Amazon Rainforest Explorer will focus on the Amazon rainforest as an ecosystem and on the wildlife that depends on it. The Amazon is the world's largest tropical rainforest and river system and contains an extraordinary amount of biodiversity. According to the World Wildlife Fund (WWF), the Amazon biome spans eight countries and French Guiana and contains about one in ten known species on Earth. The region is also important because its forests and rivers influence water cycles, store large amounts of carbon, and support millions of people. These characteristics make the Amazon an interesting topic for an educational web application because there is a large amount of information to explore, but it can be difficult for a user to organize that information into a simple learning experience.

Existing resources already provide information about the Amazon, but they often present that information through articles, reports, educational activities, or large collections of pages. For example, WWF provides extensive information about Amazon wildlife, biodiversity, people, and environmental threats, while the Smithsonian's National Zoo provides educational material and an Amazonia exhibit featuring rainforest animals. My application would take a more focused approach by allowing a user to select a broad animal group and then select a specific animal to receive a consistent set of information. The goal is not to replace these resources, but to create a simple, interactive learning tool that makes exploring Amazon wildlife easier for a student or casual visitor.

Application Description

The proposed application will be called Amazon Rainforest Explorer. The home page will introduce users to the Amazon Rainforest and explain why it is important. It will include information about the rainforest, pictures, and a short explanation of what users can explore on the website.

The main page of the application will be the Wildlife Explorer. Users will first choose an animal category: mammals, birds, reptiles, or amphibians. After choosing a category, they will choose one of four animals from that category. The second choice will depend on the first choice. After selecting an animal, the website will show information such as its name, habitat, diet, interesting facts, conservation information, and pictures.

The third page will provide general information about the Amazon Rainforest. It will include information about the rainforest ecosystem, climate, rainforest layers, biodiversity, and environmental threats. The fourth page will be a Contact Us page. It will eventually allow users to enter their name, email address, and a message or question about the website.

Two-Step Interaction and Data

The interaction is designed as a dependent two-step sequence. Step 1 determines the choices available in Step 2. Each of the 16 final animal choices will use the same information fields so that the data can later be stored consistently in JSON and a database.

  1. Step 1: Choose an animal category.
    • Mammals
    • Birds
    • Reptiles
    • Amphibians
  2. Step 2: Choose an animal from the selected category.
    • Mammals: Jaguar, Southern Two-toed Sloth, Giant River Otter, Capybara
    • Birds: Harpy Eagle, Scarlet Macaw, Toco Toucan, Hoatzin
    • Reptiles: Green Anaconda, Black Caiman, Green Iguana, Red-footed Tortoise
    • Amphibians: Strawberry Poison Dart Frog, Glass Frog, Amazon Horned Frog, Red-eyed Tree Frog

Final Information for Each Animal

Every animal selection will display the same set of data:

  • Common name and scientific name
  • Three legally reusable images with attribution when required
  • Physical description
  • Diet
  • Typical habitat
  • Geographic range or map
  • Interesting facts
  • Conservation status or conservation information

Planned Application Pages

1. Home

Introduction to the Amazon rainforest, its importance, and the purpose of the application. The page will include a large rainforest image, a short introduction, and links to the interactive wildlife explorer.

2. Wildlife Explorer

The interactive two-step page where users select an animal category and then an animal. The final selection will display the standardized animal information described above.

3. Amazon Ecosystem

A reading-focused page covering rainforest layers, biodiversity, climate, the Amazon River and basin, habitat relationships, conservation, and environmental threats. This information will not duplicate the individual animal records.

4. Contact Us

A static contact form that will eventually collect a user's name, email address, subject, and message. The form can later be connected to the course database.

Image and Data Plan

Images will be collected only from sources that permit reuse. Wikimedia Commons is one planned source because its media files are individually labeled with licensing information. Before using an image, I will check its individual file page, record the creator and license, and include the required attribution on the website. Public-domain government images may also be considered. I will not assume that an image is free to use simply because it appears in a web search.

The application will initially use manually collected data rather than a third-party API. The animal records will eventually be organized in JSON and later migrated to the database specified by the course. This approach keeps the application focused on the required web programming concepts while leaving room for additional information in later project stages.
